# NHANES 2017--March 2020 pre-pandemic files

Source: [CDC/NCHS NHANES 2017--March 2020 pre-pandemic data
page](https://wwwn.cdc.gov/nchs/nhanes/search/DataPage.aspx?Cycle=2017-2020).
The study uses these four public-use files:

- `P_DEMO.xpt`
- `P_GHB.xpt`
- `P_BMX.xpt`
- `P_BPXO.xpt`

The four files are included in this repository. Verify them with
`uv run python scripts/verify_raw_data.py`.
